# 币安U本位合约交易界面详细设计分析

> 参考币安期货交易界面进行复刻设计
> 页面: https://www.binance.com/zh-CN/futures/BTCUSDT

## 1. 设计概述

### 1.1 页面定位

币安U本位合约交易界面是一个**高信息密度**的专业交易面板，目标是让交易者能够：
- 快速执行交易操作
- 实时监控市场深度
- 便捷查看持仓和订单状态

### 1.2 整体布局

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              顶部导航栏                                      │
├─────────────┬─────────────────────────────────┬───────────────────────────┤
│             │                                 │                           │
│  左侧面板    │        中间主图表区域            │     右侧市场数据          │
│  交易下单    │        TradingView K线          │   订单簿/最新成交         │
│             │                                 │                           │
│  约280px    │        自适应宽度                │      约280px             │
├─────────────┴─────────────────────────────────┴───────────────────────────┤
│                              下方标签页区域                                   │
│              仓位 | 当前委托 | 历史委托 | 历史成交 | 资金流水                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                              底部账户信息栏                                   │
└─────────────────────────────────────────────────────────────────────────────┘
```

├────────────────────────────────────┤
│  可用    - USDT                   │  ← 账户余额
├────────────────────────────────────┤
│  ┌──────────────────────────────┐ │
│  │ 委托价格    [输入框] USDT    │ │  ← 价格输入
│  │ [ ] BBO                      │ │
│  └──────────────────────────────┘ │
│  ┌──────────────────────────────┐ │
│  │ 数量        [输入框] [BTC ▼] │ │  ← 数量输入
│  └──────────────────────────────┘ │
│  ═══════════════●═══════════════ │  ← 滑块
│  25%    50%    75%    100%      │  ← 快捷按钮
├────────────────────────────────────┤
│  预计买入: 0.0000 BTC             │
│  预计卖出: 0.0000 BTC             │
├────────────────────────────────────┤
│  ┌────────────────────────────┐   │
│  │       买入/做多             │   │  ← 买入按钮
│  └────────────────────────────┘   │
│  ┌────────────────────────────┐   │
│  │       卖出/做空             │   │  ← 卖出按钮
│  └────────────────────────────┘   │
├────────────────────────────────────┤
│  [买入/卖出 开多/开空 解释]        │
└────────────────────────────────────┘
```

### 4.2 组件详细设计

#### 4.2.1 顶部控制栏

```
┌────────────────────────────────────────┐
│ [全仓 ▼]  [20x ▼]  [S ▼]       ⚙️ 💰  │
└────────────────────────────────────────┘
```

| 元素 | 类型 | 默认值 | 交互 |
|------|------|--------|------|
| 仓位模式 | 下拉按钮 | 全仓 | 点击切换 全仓/逐仓 |
| 杠杆 | 下拉按钮 | 20x | 点击选择杠杆倍数 |
| 方向 | 切换按钮 | S(空) | 点击切换 S(空)/L(多) |
| 设置 | 图标按钮 | - | 点击打开设置面板 |
| 资金 | 图标按钮 | - | 点击打开资金管理 |

#### 4.2.2 订单类型Tab

```
┌──────────────────────────────────────┐
│ [限价]  [市价]  [限价止盈止损 ▼]     │
└──────────────────────────────────────┘
```

| Tab | 说明 | 显示字段 |
|-----|------|----------|
| 限价 | 限价委托 | 价格 + 数量 |
| 市价 | 市价委托 | 仅数量 |
| 限价止盈止损 | 条件委托 | 价格 + 数量 + 止盈/止损价格 |

#### 4.2.3 价格输入区域

```
┌────────────────────────────────────┐
│ 委托价格                             │
│ ┌────────────────────────┐ USDT   │
│ │ 70,796.3               │        │  ← 数字输入框
│ └────────────────────────┘        │
│ ☑ BBO (使用最优买一/卖一价格)      │  ← 复选框
└────────────────────────────────────┘
```

**设计要点**:
- 输入框宽度: 100%
- 边框圆角: 8px
- 聚焦边框色: #FCD535
- 数字格式化: 千位分隔符

#### 4.2.4 数量输入区域

```
┌────────────────────────────────────┐
│ 数量                                │
│ ┌────────────────────────┐ [BTC▼] │
│ │                        │        │  ← 数字输入框 + 单位下拉
│ └────────────────────────┘        │
│ ═══════════════●═══════════════   │  ← 滑块
│  25%    50%    75%    100%       │  ← 快捷按钮
└────────────────────────────────────┘
```

**设计要点**:
- 滑块颜色: #FCD535
- 滑块轨道颜色: #333B47
- 快捷按钮点击填充滑块

#### 4.2.5 买卖按钮

```
┌────────────────────────────────────┐
│ 买入/做多   (绿色按钮)              │
│ 卖出/做空   (红色按钮)              │
└────────────────────────────────────┘
```

| 按钮 | 背景色 | 文字色 | 圆角 |
|------|--------|--------|------|

// 数量格式: 最多8位小数

## 14. 实现建议

### 14.1 技术栈

- **框架**: Vue 3 + TypeScript
- **状态管理**: Pinia
- **图表**: TradingView Lightweight Charts
- **样式**: SCSS / Tailwind CSS

### 14.2 目录结构

```
src/
├── components/
│   └── trading/
│       ├── TradingPanel.vue        # 左侧交易面板

│       ├── PositionMode.vue        # 持仓模式
│       ├── OrderBook.vue           # 订单簿

│       ├── PositionList.vue        # 仓位列表
│       ├── OrderList.vue           # 委托列表
